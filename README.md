💪 FitBuddy – AI Fitness Plan Generator Using Gemini Models
📌 Project Overview
FitBuddy is an AI-powered fitness plan generator developed using Python, Streamlit, and Google Gemini Models.

The application takes basic user information such as age, fitness level, fitness goal, available workout days, workout duration, available equipment, and preferred activities. Based on these inputs, the Gemini AI model generates a simple and personalized general fitness plan.

The main aim of this project is to demonstrate how Generative AI can be integrated with a Python application to provide personalized and user-friendly fitness guidance.

🎯 Project Objective
The objective of FitBuddy is to develop a simple AI-based application that:

Collects basic fitness-related information from the user.
Uses a Gemini AI model to analyze the provided information.
Generates a personalized general fitness plan.
Provides the result through a simple and interactive web interface.
Demonstrates the practical use of Generative AI in a real-world application.

🚀 How to Run the Project
1. Clone the repository
git clone https://github.com/your-username/FitBuddy.git
2. Open the project folder
cd FitBuddy
3. Install the required libraries
pip install -r requirements.txt
4. Run the Streamlit application
streamlit run app.py
5. Open the application
After running the command, Streamlit will provide a local URL such as:

http://localhost:8501
Open this URL in your browser.

🔑 Gemini API Key
The application requires a Gemini API key to generate the AI fitness plan.

For security reasons, the API key should not be uploaded or hard-coded in the GitHub repository.
