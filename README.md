## Project Overview

FitBuddy is an AI-assisted fitness planning web application intended to generate personalized seven-day workout plans based on user-provided fitness details, goals, and preferred intensity. The project documentation describes Google Gemini integration, database storage, feedback-based plan revision, and nutrition tips.

## Technology Stack

- Python and FastAPI
- HTML, CSS, JavaScript, and Jinja2 templates
- SQLAlchemy and SQLite/configured SQL database
- Pydantic
- Google Gemini SDK
- python-dotenv, if used by the included source

2. Install the dependencies listed in the actual project dependency file.

4. Configure and initialize the database as required by the source.
5. Run the application using the entry point documented in the source project.

**Never commit API keys or real user data.** Generated exercise and nutrition content is general AI output, not medical advice. Test the application and replace any suggested test/demo details with actual evidence before submission.
